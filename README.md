A fast, easy-to-use make.fun frontend from static files on make.fun's public API: the live bounty board with each bounty's reward and live pot, its entry fee and time left; a bounty's page with its rules and rewards; its leaderboard; and an account's public profile.

## Run it

```sh
python3 -m http.server 8000 --directory app
```

Then open http://localhost:8000 in a browser.
